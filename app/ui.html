五要素对照

① FastAPI 业务闭环

缺陷登记 → 部位定位 → 红线识别 → 人工复核留痕 → 审计记录，13 个接口可直接调用。

② Harness 评估

G0–G4 五道关卡自动打分，覆盖口径、数据、定位、红线、权限边界。

③ RAG 知识库 + 图谱

63 条带事实编号的合成语料，检索结果附来源与编号，另有知识图谱与 Mermaid 视图。

④ 权限分层

HMAC 签名令牌；admin / 验房员 / 整改专员 / 质量经理 / 观察员五级权限，越权返回 403。

⑤ 在线部署

单端口 HTTP 服务，公网可访问；本页即为部署入口，完整接口见 /docs。
