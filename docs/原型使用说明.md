# 可运行原型使用说明

> 本原型把提示词落成可运行内核，覆盖定位、红线与审计三条主链路。
> 零第三方依赖，Python 3.9+，只读、不联网、不写回任何业务系统（f32）。

---

## 一、快速开始

在仓库根目录执行：

```bash
# 1. 内置自检（约 0.01 秒）
python src/main.py --self-test

# 2. 离线演示：6 条缺陷 → 定位候选 + 红线 + 审计
python src/main.py --demo

# 3. 提示词模式：输出可发给模型的完整提示词（不调用模型）
python src/main.py --mode prompt --demo

# 4. 独立测试套件（12 项）
python -m unittest discover -s tests -v

# 5. 保存结果到文件
python src/main.py --demo --out report.json
```

无需 `pip install`。只需 Python 解释器。

## 三、样例数据说明

`src/data/sample_defects.json` 含 6 条合成缺陷、7 张工单，刻意覆盖：

| 缺陷 | 场景 | 预期判定 |
| --- | --- | --- |
| D-1001 | 正常定位（客厅） | 候选建议待人工确认 |
| D-1002 | 正常定位（主卧） | 候选建议待人工确认 |
| D-1003 | 未复验却已关单 | R1 转人工 |
| D-1004 | 描述写厨房、照片为客厅 | 冲突转人工，置信度压低 |
| D-1005 | 资料缺依据 + 两版本冲突 + 交接未确认 | R2+R3 转人工 |
| D-1006 | 关键系统不可用 | R4 转人工 |

`src/data/unit_parts.json` 为模拟户型部位字典（版本 floorplan-v3），不对应真实户型图。

## 四、边界声明

1. 本原型只产出**候选建议**和**转人工提示**，不产生任何业务动作。
2. `needs_confirmation` 恒为 true；采纳与否由具名人员决定（f22）。
3. 审计记录中的"人工改动"和"签核人"字段留空，不自动填充（f45）。
4. 98% 是缺陷定位准确率，判定人与样本量尚未核实（f02/f42），本原型不声称达标。
5. 合成训练场景不代表真实授权、业务执行或客户验收。
