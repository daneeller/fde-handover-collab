## 四、可运行原型（代码）

### 快速开始

```bash
python src/main.py --self-test              # 内置自检
python src/main.py --demo                   # 离线演示：6 缺陷 → 候选 + 红线 + 审计
python src/main.py --mode prompt --demo     # 输出可发模型的完整提示词（不调用模型）
python -m unittest discover -s tests -v     # 12 项自动化测试
```

**零第三方依赖**，Python 3.9+ 直接运行，不联网、不写回任何业务系统（f32）。

### 已实现的能力

| 能力 | 代码 | 事实编号 |
| --- | --- | --- |
| 缺陷描述 + 照片元数据 → 户型部位候选 | `src/locator.py::locate` | f10 / f42 |
| 描述—照片冲突压低置信度并转人工 | 同上 | f10 / f15 |
| 四类异常红线阻断（未复验关单 / 资料缺依据 / 规则冲突 / 系统不可用） | `src/rules.py::detect_red_lines` | f11 / f24 / f35 / f44 |
| 主编号去重（一缺陷多工单，避免复验通过率重复计数） | `src/rules.py::dedupe_by_master` | f31 / f33 / f53 |
| 快照超期标「待刷新」 | `src/rules.py::stale_snapshot` | f34 / f35 |
| 交接五要素 + 对方确认 | `src/rules.py::handover_complete` | f23 |
| 审计留痕六要素 | `src/audit.py::build_audit` | f45 |
| 提示词模板与来源声明 | `src/prompts.py` | f10 / f15 / f42 |

### 安全边界

1. 只产出**候选建议**与**转人工提示**，不产生业务动作。
2. `needs_confirmation` 恒为 true；采纳与否由具名人员决定（f22）。
3. 审计记录中"人工改动""签核人"留空，不自动填充（f45）。
4. 98% 是**缺陷定位准确率**，判定人与样本量尚未核实（f02/f42），本原型不声称达标。
5. 只读接入，不回写工单、不自动关单、不代替客户签字与质量鉴定（f05/f32/f40）。

## 五、关键结论摘要

1. 优先验证「照片—户型部位—返工位置」缺陷定位辅助，直接对应重复缺陷占比与分派核对耗时（f10/f00）。
2. 「未复验关单」需强制人工兜底，是明确的验收红线（f11/f42）。
3. 复验通过率统计口径须先统一（一缺陷多工单导致重复计数，f31/f33）。
4. 「完成」定义需跨岗统一（施工＝整改结束，客户＝复验通过，f50）。
5. 权限与审批边界需先形成矩阵，AI 建议仅限只读提示，不触发状态变更（f22/f24/f41）。
